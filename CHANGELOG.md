# Changelog

## 0.1.0 — 2026-09-13

Initial release.

- Telegram bot with long polling (grammY): /start, /edit, /help, /stats, /qr, /export
- Inline query support: type @biogram_bot username in any chat
- REST API for profiles, tiles, and click analytics
- React Mini App with Telegram SDK integration
- Public Bento grid view with five tile types (GitHub, Social, Tip, Video, Contact)
- Edit mode with drag-and-drop tile reordering
- Four visual themes: Obsidian Dark, Cyberpunk, Glassmorphic, Minimal Paper
- Click analytics with per-tile breakdown
- QR code generation for profile links
- Profile data export as JSON
- Demo mode with pre-seeded sample profile
- Docker support with multi-stage build
- SQLite database in WAL mode
